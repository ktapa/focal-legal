# focal-legal

The public privacy policy and terms of service for Focal, served by GitHub Pages.

This repository holds only those two static pages and a small index linking to them. It contains no application code. There is no build step: the pages are plain HTML and CSS.

- Privacy Policy: https://ktapa.github.io/focal-legal/privacy/
- Terms of Service: https://ktapa.github.io/focal-legal/terms/
